# 📊 PR. 1 – FUNDAMENTAL BOOSTER
### Excel Formula Practice Workbook

---

## 📌 Project Overview

**Fundamental Booster** is an Excel-based practice project created to strengthen essential spreadsheet skills through practical examples. The workbook contains three different datasets—**Students Grade, Sales Data, and Employee Data**—and uses Excel formulas to perform calculations, apply logical conditions, process dates, and manipulate text.

The purpose of this project is to understand how Excel formulas work with real-style data and how they can make everyday calculations faster and easier.

---

## 🎯 Project Objectives

- Practise commonly used Excel formulas.
- Perform calculations automatically using cell references.
- Apply logical conditions to classify and evaluate data.
- Extract useful information from dates.
- Clean and transform text values.
- Understand how formula results update when source data changes.

---

## 📁 Workbook Structure

The workbook contains the following three worksheets:

### 1. Students Grade

This sheet contains student information, subject marks, and enrollment dates.

**Tasks performed using formulas:**

| Column | Purpose |
|---|---|
| Average Score | Calculates the average of Math, Science, and English marks. |
| Grade (IF) | Assigns a grade based on the average score. |
| Pass/Fail (IF) | Displays Pass when the average is 50 or more; otherwise, Fail. |
| Both Math & Science > 80 (AND) | Checks whether both subject marks are above 80. |
| Discount Eligible (OR) | Checks whether at least one subject mark is above 90. |
| Name UPPER | Converts the student's name into uppercase. |
| Enrollment Year | Extracts the year from the enrollment date. |

**Excel functions used:** `AVERAGE`, `IF`, `AND`, `OR`, `UPPER`, `YEAR`

### 2. Sales Data

This sheet contains sales records with product names, regions, salesperson names, amounts, and dates.

**Tasks performed using formulas:**

| Column | Purpose |
|---|---|
| Discount? (IF/OR) | Displays Yes if the amount is above 30,000 or the product is Laptop. |
| Sale Month | Displays the sale month and year in MMM-YYYY format. |
| Sale Year | Extracts the year from the sale date. |
| Amount Category | Classifies sales as High, Medium, or Low. |
| Amount Rounded ($) | Rounds the amount to the nearest hundred. |

**Excel functions used:** `IF`, `OR`, `TEXT`, `YEAR`, `ROUND`

### 3. Employee Data

This sheet contains employee details such as name, department, salary, and joining date.

**Tasks performed using formulas:**

| Column | Purpose |
|---|---|
| Years of Service | Calculates the employee's service duration using the joining date. |
| Joining Year | Extracts the joining year. |
| Salary Band | Classifies salary as Junior, Mid-Level, or Senior. |
| First Name (LEFT) | Extracts the first name from the full name. |
| Name UPPER | Converts the name into uppercase. |
| Name LOWER | Converts the name into lowercase. |
| Annual Bonus (10%) | Calculates 10% of the employee's salary. |

**Excel functions used:** `ROUND`, `TODAY`, `YEAR`, `IF`, `LEFT`, `FIND`, `UPPER`, `LOWER`

## ▶️ How to Run the Project

1. Download the Excel workbook: `PR_1 Fundamental_Booster_.xlsx`.
2. Open the file using **Microsoft Excel**.
3. Select a worksheet from the bottom sheet tabs:
   - Students Grade
   - Sales Data
   - Employee Data
4. Review the data and the formula-based columns.
5. Click any formula cell to view its formula in the Formula Bar.
6. Change a sample input value to see how the related formula result changes.
7. Save your workbook after practising.

---

## 📝 Important Notes

- This project is an **Excel workbook (.xlsx)**.
- Formula results are calculated automatically by Microsoft Excel.
- The `TODAY()` function uses the current date, so Years of Service may change over time.
- Do not delete the source data or formula columns while practising.
- If formula results do not update, check that Excel calculation mode is set to **Automatic**.
